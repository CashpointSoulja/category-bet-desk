# Five Whys

Problem statement: **a category bet can run for months before anyone can say clearly whether to scale it or kill it.**

This is a hypothesis about new-category work in general, built from the public job post. It is not a reported Fleek problem.

1. **Why is there no clear call?** Because the evidence that decides it (margin per bundle, repeat buying, disputes, grading quality) arrives in pieces and is never put side by side.
2. **Why is it never side by side?** Because the thesis, the P&L and the pilot readout are made at different times by different people, in different files.
3. **Why does that matter for the call?** Because a bet can look healthy on one view and fail on another: good margin per bundle but a ramp that never reaches £5M, or fast GMV growth carried by a dispute rate that eats the take.
4. **Why don't the thresholds settle it?** Because if thresholds are agreed after the first data comes in, they tend to move to fit it, and it is not clear which numbers are measured and which are placeholders.
5. **Why is that hard to see?** Because nothing marks a number as sourced, estimated or placeholder, and nothing stops a decision being taken on a thin sample.

**Root cause:** there is no single, honest working case per bet that links thesis → bundle economics → ramp → pre-set gates, and shows the evidence quality of each number.

**What the desk does about it:** one screen per bet; every input labelled; scale and kill lines with minimum samples; a gate that holds on missing or thin evidence; and a one-page memo that shows how many inputs are still placeholders.
