# Jobs to be done

## Primary: the bet owner (Special Projects Lead, Category Expansion)

**When** I pick up a new category idea, **I want to** write down who buys it, who supplies it and why Fleek wins, and see straight away what a bundle earns, **so that** I can drop weak ideas before I spend weeks signing suppliers.

**When** I have first supplier quotes and grading samples, **I want to** replace placeholders with real numbers and see which inputs move contribution most, **so that** I know which quote or test to chase next.

**When** I set up the pilot, **I want to** agree scale and kill lines and minimum samples before any orders come in, **so that** nobody can move the goalposts later, including me.

**When** pilot data arrives, **I want** a gate call that says scale, hold or kill and why, **so that** I can bring a clear recommendation to the founders.

**When** I go into the decision meeting, **I want** one printed page with the thesis, economics, ramp, gates, risks and how much of it is still a guess, **so that** the discussion is about the decision, not about finding the numbers.

## Secondary: founders and functional leads

- **Founders:** compare bets on the same terms and see which one can actually reach £5M GMV.
- **Supply lead:** see how many suppliers, and at what listing pace, the ramp needs.
- **Growth lead:** see how many buyers per month, at what retention and CAC, the ramp needs, and how much of it comes from buyers already on Fleek.
- **Operations / grading:** see the grading agreement threshold and the dispute rate the bet can carry before it dies.

## Forces

| Push (today) | Pull (desk) |
|---|---|
| Evidence spread across files | One screen per bet |
| Thresholds set late | Thresholds set before the pilot, kill lines checked against scale lines |
| Guesses look like facts | Sourced / estimated / placeholder on every input |

| Anxiety | Habit |
|---|---|
| "The model is too simple" — answered by showing every formula and the sensitivity tables | Existing spreadsheets — answered by keeping the inputs the same ones a spreadsheet would have |
